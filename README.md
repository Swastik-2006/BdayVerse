# 🎂 BdayVerse

A personalised birthday surprise website to make someone's special day memorable. Create a unique birthday experience with photos, captions, inside jokes, and secret messages — all shareable through one link.

🌐 **Live Website:** https://bdayverse.embarko.app/

## ✨ Features

- Personalised birthday pages
- Add photos and captions
- Interactive inside-joke cards
- Secret personal messages
- Animations and interactive elements
- Unique shareable links

## 🚀 How to Use

1. Visit [BdayVerse](https://bdayverse.embarko.app/).
2. Enter the recipient's name.
3. Add photos, jokes, and personal messages.
4. Create your surprise and copy the generated link.
5. Share it with the birthday person!

The recipient can simply open the link and enjoy the surprise.

## 🛠️ Built With

- HTML, CSS & JavaScript
- Supabase — Database and photo storage
- Embarko — Deployment

**BdayVerse is a fully AI-assisted project.** AI tools like Claude and ChatGPT were used throughout the development process, from frontend creation and backend integration to debugging and deployment. The idea, creative direction, and feature requirements were guided by me.
