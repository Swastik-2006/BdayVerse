# 🎂 BdayVerse — Create a Birthday Surprise That Feels Personal

**BdayVerse** is a personalised birthday surprise website where you can create a unique digital birthday experience for someone special. Add their name, photos, memories, inside jokes, and secret messages — then share the surprise through a single link.

🌐 **Live Website:** https://bdayverse.embarko.app/

---

## ✨ What Can BdayVerse Do?

- 🎉 **Personalised Birthday Experience** — Create a birthday page with the recipient's name.
- 📸 **Photo Memories** — Add personal photos with captions.
- 💬 **Inside Jokes** — Create interactive flip cards featuring your favourite inside jokes.
- 💌 **Secret Message** — Include a personal message for the recipient.
- 🎨 **Interactive Experience** — Enjoy animations and visual elements throughout the birthday surprise.
- 🔗 **Shareable Link** — Generate a unique link and send it directly to the birthday person.

## 🚀 How to Access and Use BdayVerse

No installation or account setup is required to experience a shared birthday surprise.

### For the Creator

1. Visit [BdayVerse](https://bdayverse.embarko.app/).
2. Open the creator setup.
3. Enter the recipient's name.
4. Add photos, captions, inside jokes, and personal messages.
5. Create your birthday surprise.
6. Copy the generated unique link.
7. Share it with the birthday person!

### For the Recipient

1. Open the unique link shared by the creator.
2. Experience the personalised birthday surprise.
3. Explore the photos, interactive cards, and secret message.

**The recipient gets the surprise experience, not the creator setup.**

## 🗄️ Database Setup

This repository includes `supabase.sql`, which contains the database setup required for the project.

To configure your own Supabase project:

1. Create a project at [Supabase](https://supabase.com/).
2. Open the SQL Editor.
3. Copy the contents of `supabase.sql`.
4. Run the SQL script.
5. Configure your own Supabase project credentials in `index.html`.

**Note:** The included frontend configuration is connected to the original project. Use your own Supabase credentials if deploying your own independent instance. Never expose your Supabase service role or secret key in frontend code.
